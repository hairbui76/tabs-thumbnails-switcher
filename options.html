Options

Logging appears in the service worker (Extensions → Inspect views) and the page devtools for each tab, only when this is on.

Overlay (when the tab switcher is open)

Click Change…, then press the key combination for each action. Use Escape to cancel a capture. If “Use arrow keys to navigate” is on, Arrow Up / Arrow Down also move the selection (plain arrows, no modifiers).

Sort button

The switcher header has a Sort button next to the gear (or press S while the switcher is open). It reorders the tabs by: most recently used site first → tabs of the same site grouped together → newest visit first within a site. This also moves the real tabs in the Chrome tab strip. Pinned tabs and tab groups are preserved — sorting happens inside each of them, so nothing leaves its group.

Quick switch: Ctrl+Tab (advanced)

Chrome’s shortcut editor usually will not assign Ctrl+Tab to an extension (the browser uses it for built‑in tab switching). You can still try to bind it to Quick switch: previous tab (MRU) using Chrome’s internal API from the shortcuts page only:

  1. Open chrome://extensions/shortcuts (copy the URL if the link does not open from this page).
  2. Turn on Developer mode (top right on chrome://extensions).
  3. Open Developer Tools for that tab (e.g. right‑click → Inspect, or Ctrl+Shift+J).
  4. In the Console, paste the snippet below (your extension id is filled in automatically) and press Enter.

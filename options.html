Logging appears in the service worker (Extensions → Inspect views) and the page devtools for each tab, only when this is on.

Overlay (when the tab switcher is open)

Click Change…, then press the key combination for each action. Use Escape to cancel a capture. If “Use arrow keys to navigate” is on, Arrow Up / Arrow Down also move the selection (plain arrows, no modifiers).

Keep holding the shortcut that opened the switcher, cycle, then let go of Ctrl to switch. Enter and Escape keep working. Off by default: with it on, opening the switcher and letting go to reach for the mouse would switch tabs.

To cycle while holding, tap the open shortcut again (with Ctrl+Shift+Q, keep Ctrl+Shift down and tap Q), or use ↓ / ↑. Tab cannot be used here: Chrome reserves Ctrl+Tab for its own tab switching and never delivers it to a page, so the switcher never sees it.

Tab count

The toolbar icon shows a badge with the number of tabs open in the focused window (999+ past 999), and its tooltip spells the number out. The switcher header repeats it as a pill next to the title, plus a cross-window total when you have more than one window open. Only normal browser windows count — not popups, app windows or devtools.

Sort button

The switcher header has a Sort button next to the gear (or press S while the switcher is open). The 10 most recently visited tabs lead, newest first; everything after them is grouped by domain → tab title → visit time. This also moves the real tabs in the Chrome tab strip. Pinned tabs and tab groups are preserved — sorting happens inside each of them, so nothing leaves its group.

Binding Tab shortcuts (advanced)

Chrome’s shortcut editor will not assign anything containing Tab to an extension — the commands API does not accept Tab as a shortcut key at all. Chrome’s internal API will, from the shortcuts page.

The two commands, and what they are bound to right now:

The pairing worth having is Ctrl+Tab to jump straight to the previous tab and Ctrl+Shift+Tab to walk the switcher. With Switch on modifier release on, that reproduces Alt+Tab exactly: hold Ctrl+Shift, tap Tab down the list, let Ctrl go to jump.

  1. Open chrome://extensions/shortcuts (copy the URL if the link does not open from this page).
  2. Turn on Developer mode (top right on chrome://extensions).
  3. Open Developer Tools for that tab (e.g. right‑click → Inspect, or Ctrl+Shift+J).
  4. Paste this into the Console and press Enter. Your extension id is filled in already; edit keybinding for anything else.

      
Cycling with Tab works only when bound this way. Pressed as a plain keystroke, Ctrl+Tab never reaches the switcher: Chrome keeps it for its own tab switching and does not deliver it to pages at all. Bound as a command it arrives through the extension API instead.

      
Uses chrome.developerPrivate, which exists on that internal page when Developer mode is on. It is not a stable public API—Chrome may change behavior. Only paste code you trust. To undo, rebind to something ordinary or press Reset beside the shortcut on chrome://extensions/shortcuts.
